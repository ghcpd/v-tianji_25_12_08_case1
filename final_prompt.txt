Refactoring Capability Test Prompt

Task Description:
You are tasked with refactoring a React frontend codebase that contains significant code duplication and unclear logic patterns. Your goal is to:

Identify all code duplication (both obvious and subtle)

Refactor unclear logic in agent tools and utility functions

Fix any bugs introduced by duplication

Generate a PR-ready summary with code diffs in unified diff format
All results must be written to an output file.

Requirements:

Code Analysis

Analyze the entire codebase for duplication patterns (exact duplicates, semantic similarities, cross-file duplicates)

Identify unclear logic in agent tools (src/utils/agentTools.js, src/utils/requestHandler.js, src/utils/dataProcessor.js)

Find semantic similarities across different files that can be unified

Detect any bugs in duplicated code

Refactoring Implementation

Consolidate duplicate functions into single implementations

Extract common patterns into reusable utilities

Unify similar logic across different files

Fix bugs introduced by duplication

Maintain backward compatibility with existing components

Update all imports and references accordingly

Testing

Create and run test cases to verify refactored code works correctly

Ensure all existing functionality is preserved

Test edge cases and error handling

All tests must pass before submitting

Output Format:
A. Pull Request Title:
refactor: Consolidate duplicate functions and improve code clarity

B. PR Description Template:
Summary:
Brief description of what was refactored and why.
Changes Made:

List of major changes

Functions consolidated

Bugs fixed
Testing:

Test cases added/updated

Verification steps
Files Changed:

List of files modified

C. Code Diffs (Unified Diff Format):
All code changes MUST be provided in unified diff format. Do not wrap in code blocks. Provide raw text diffs only. All output should be saved into a single output file.
