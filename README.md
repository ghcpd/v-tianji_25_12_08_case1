# Agent Tools Frontend

A complex frontend application built with React and Vite for managing agent tools, data processing, and notifications.

## Features

- Dashboard with real-time statistics
- Agent Tools execution and management
- Data processing with transformation and filtering
- Notification center

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

- `src/components/` - React components
- `src/utils/` - Utility functions and agent tools
- `src/App.jsx` - Main application component
- `src/main.jsx` - Application entry point

## Technologies

- React 18
- Vite
- React Router
- Zustand (state management)
- Axios (HTTP client)
